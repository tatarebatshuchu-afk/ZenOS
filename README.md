# ZenOS 1.0 + ZenBIOS для OpenComputers

Требования: Lua 5.3 (по умолчанию в OC 1.7+), экран + видеокарта + клавиатура,
RAM от ~512 КБ (2 планки tier 1.5 или лучше), жёсткий диск/дискета, EEPROM.

## Установка

**Способ 1 — один файл (`zenos-install.lua`).** Загрузите файл на компьютер с OpenOS
(`wget https://.../zenos-install.lua`, либо скопируйте в папку диска мира),
затем `lua zenos-install.lua`: выбор диска → копирование → прошивка ZenBIOS.

**Способ 2 — вручную.** Содержимое папки `zenos/` положите в корень диска
(в одиночной игре: `saves/<мир>/opencomputers/<uuid диска>/`). BIOS прошейте в OpenOS:
`flash -q zenbios.lua` (либо `flash zenbios.lua` в самой ZenOS).

**Способ 3 — из ZenOS:** команда `install` копирует систему на другой диск.

## ZenBIOS (EEPROM, < 4 КБ)
- автозагрузка с сохранённого диска, любая клавиша за 1.5 с → меню загрузки;
- поиск дисков с `/init.lua`, сетевая загрузка (internet card), Lua-prompt, перезагрузка;
- показ ошибок загрузки + звуковой сигнал.

## Возможности ZenOS
планировщик процессов (корутины, события, таймеры), виртуальная ФС с автомонтированием
(`/mnt/xxx`, `/tmp`), терминал с ANSI-цветами, историей, Tab-автодополнением, Ctrl+C/Ctrl+D;
шелл: кавычки, `$VAR`, `| > >> <`, `&& || ; &`, `* ?`, алиасы, скрипты `.sh`;
пользователи и пароли (`passwd`), `/etc/profile.lua`, `/etc/rc.d/*.lua`;
команды: `help` покажет полный список.

## Ограничения
Пароли хешируются простым солёным хешем (защита «от случайных», не криптография).
Тестировалось на эмуляции API OpenComputers, не в самой игре — возможны мелкие отличия.
